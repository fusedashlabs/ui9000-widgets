# Engine catalog accessibility

Checked against Stage 2 close-out (engine ids only). Shadow DOM: names come from `aria-label` on the host/root, never `aria-labelledby` across the iframe.

| Id | Labels | Keyboard | Notes |
|----|--------|----------|-------|
| bar-chart / histogram-chart / network-graph / map-chart / kpi-widget | Existing chart `aria-label` on SVG/host | Tab into chart chrome | Unchanged this close-out |
| table | region `Evidence table`; row `tabindex=0` | Tab rows, Enter/Space selects | Sticky opaque `thead` |
| text | region `Text`; markdown links http(s) | Tab to links | No `innerHTML` |
| image | `alt` on `img` | Tab onto image | http(s) only |
| event-timeline | `aria-label` on list; buttons per event | Tab through events | |
| evidence-panel | `aria-label` = claim | Tab sources | Child table/text/image keep their own labels |
| entity-detail | `aria-label` = title | Tab fields/actions | |
| text-input, number-input, select, multi-select, checkbox, date-input | `<label for>` | Tab into control | No label → no interactive control |
| button | Visible label | Tab, Enter | Emits `ui9000-action` |
| form | `aria-label` from form label; child labels | Tab order then Submit | |
| approval-bar | region `Approval` | Tab Approve / Reject | Display-only in foreign hosts |

**Bar:** Storybook Engine/Playground stories + unit tests for unlabelled controls and table select. Critical: unlabelled control must not render an input (fail-closed).

**Limitation:** `aria-labelledby` does not cross the shadow boundary.
